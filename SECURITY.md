# Saugumas / Security

Never post passwords, session cookies, form tokens, account IDs, exact object
addresses, or full authenticated portal pages in public issues.

Report security vulnerabilities privately through GitHub's **Security → Report
a vulnerability** for this repository. Public issues are for non-sensitive bugs.
The latest released integration version receives fixes. Credentials are stored
by Home Assistant in its config-entry storage; protect your HA configuration and
backups. Portal cookies are held in memory only.
